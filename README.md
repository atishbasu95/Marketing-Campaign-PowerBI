# Marketing Campaign Analysis Dashboard

## Project Overview
Interactive Power BI dashboard analyzing marketing campaign 
performance across regions and platforms.

## Tools Used
- Power BI Desktop
- DAX
- Power Query

## Dataset
- Marketing_Campaign_Performance.csv (1000 rows)
- Marketing_Campaign_Details.csv
- Region_Performance.csv

## Key Features
- KPI Cards: Total Revenue, Spend, ROI, Best Campaign
- Stacked Column Chart: Spend vs Revenue by Region
- Combo Chart: Spend and ROI by Campaign
- Bar Chart: ROI by Campaign
- Pie Chart: Campaigns by Type
- Gauge Chart: ROI vs Target
- Slicers: Region and Campaign Type

## Key DAX Measures
- Total Revenue
- Total Spend
- Average ROI
- Total ROI
- Best Campaign by ROI

## Key Insights
- Total Revenue: $42.5M
- Total Spend: $25.7M
- Average ROI: 68%
- North America has highest ROI at 75%
- Oceania has lowest ROI at 62%
